## 1. Что за приложение

**BrainstormBuddy** — Windows-оверлей (WPF, .NET 8) для онлайн-созвонов: слушает микрофон
и системный звук, распознаёт речь локальной STT-моделью, отправляет мульти-агентным LLM
(TechLead + HRD) и показывает подсказки поверх всех окон в реальном времени.
Ключевое: окно **скрыто от захвата экрана** (собеседник в Zoom его не видит), click-through
режим, всё работает **локально** (локальный LLM + Docker), без облака.

Пользователи: пресейл-инженеры, рекрутеры, кандидаты на собеседованиях.
Персонаж бренда: «надёжный интеллект» — профессиональный инструмент, не игрушка.
ЗАПРЕЩЕНО: хакер/матрица-эстетика, эмодзи в UI. Тон — Corporate Modern + Glassmorphism.

## 2. Окна для отрисовки (все состояния)

### 2.1 Главное окно — Оверлей (`asis/overlay_*.png`)
Компактное (560×500, ресайзится 420×300+), поверх всех окон, тёмное, полупрозрачное (0.92).
Зоны сверху вниз:
1. **Тайтлбар** (drag): логотип, селектор системного промпта (комбо), чипы статусов
   REC (пульс красным при записи) и LLM (пульс синим при отправке), кнопки:
   пауза LLM, пауза аудио, настройки, автоскролл.
2. **Тулбар**: два слайдера с подписями над треком (ТИШИНА · 1.8s / ЧАНК МАКС · 60s);
   ряд действий: «отправить сейчас» (молния), экспорт, AI-протокол, скриншот-режим,
   медленнее/сброс/быстрее речь, сквозной режим, очистить, скрыть.
3. **Статус-строка**: «Слушаю…» / «Думаю…» / ошибки.
4. **История Q/A** (скролл): пары ВОПРОС (курсив, приглушённый, с mono-таймингами
   ←STT 15:33:30.120 · STT 1.0s · aud 15.0s) и ОТВЕТ-карточка (рамка, лейбл, текст,
   Σ-латентность с цветом зелёный/жёлтый/красный); опциональные блоки:
   **HRD СОВЕТ** (синяя карточка), **ЗАЩИТА** (янтарная), **РАСШИРЕННЫЙ ОТВЕТ** (золотая);
   слева у пары точка статуса (синяя=отправка, зелёная=готово, красная=ошибка);
   зелёная рамка фокуса вокруг выбранной пары; контекст-меню (копировать/расширить/фокус).
5. **Эквалайзер АУДИО** (сворачиваемый ▾): бары 2 минут звука с временной линейкой;
   цвета: розово-красный=речь, синий=STT-фаза, зелёный=ответ, серый=тишина.
6. **Футер**: счётчик токенов (mono), часы, скруглённое поле «Секретное сообщение в LLM…»
   с круглой кнопкой отправки.

Состояния для мокапов: обычный поток; пауза аудио; пауза LLM; ошибка STT/LLM;
пустая история (первый запуск); свёрнутый эквалайзер; узкая ширина 420px.

### 2.2 Настройки (`asis/settings_*.png`)
Отдельное окно 720×600: сайдбар слева (активный пункт — зелёная полоса), контент справа,
футер (Открыть папку / Сохранить (primary) / Закрыть). 10 вкладок:
API (пресеты провайдеров, URL, ключ, модели), LLM (пресеты системных промптов: список +
редактор), Аудио (устройства, 6 слайдеров VAD-параметров, Live RMS-индикатор),
Локальный STT (статус Docker-контейнера, кнопки Запустить/Остановить/Удалить/Пинг,
метрики CPU/RAM/ping/uptime mono, лог сборки), Оверлей (прозрачность, позиция, шрифт,
тема тёмная/светлая, ЯЗЫК ru/en, папка экспорта), Горячие клавиши, О приложении,
Профиль, Агенты (сценарии мульти-агентов, вкл/выкл агентов), LLM Логи.

### 2.3 Окно логов (`asis/logwindow*.png`)
640×320: фильтр уровня, чекбоксы автопрокрутка/пауза, моноширинный список с цветами
уровней, кнопки Очистить/Копировать/Открыть папку.

## 3. Иконки — полный комплект

### 3.1 Иконки приложения для Windows (НЕТ — нарисовать с нуля!)
За основу — фирменный знак «мозг-лампочка» (`design/icons/stitch/app_icon_tray_icon/`).
- **app.ico**: мультиразмер 16/24/32/48/64/128/256 px (рабочий стол, панель задач,
  Alt-Tab, проводник). На 16px знак должен оставаться читаемым — упрощённая версия.
- **tray.ico** 16/32: обычное состояние + варианты: пауза (приглушённый),
  запись активна (красная точка-бейдж), ошибка (янтарная точка).
- Taskbar overlay badges (16×16): recording / paused / error.

### 3.2 Иконки UI (SVG 24×24, material filled — стиль уже задан в design/icons/stitch)
Есть у дизайнера (перерисовать в едином комплекте): settings, pause, play_resume,
auto_scroll, export, ai_protocol, screenshot, erase, close, help.
Отсутствуют (сейчас самодельные, нужны фирменные): send_now (молния, жёлтая),
cloak (глаз/сквозной режим), llm (робот), chat_send (самолётик),
slow_speech / reset_speed / fast_speed, chevron collapse/expand,
язык (ru/en переключатель), Docker-контейнер (для вкладки Локальный STT),
микрофон, динамик, тема (луна/солнце).

## 4. Атомы дизайн-системы (отрисовать библиотеку)
Кнопки: primary (мятная), ghost, иконочная 28×24, круглая отправка 30px, деструктивная.
Инпуты: текстовый (radius 8, focus-глоу мятный), многострочный mono, PasswordBox, placeholder.
Чипы-статусы: idle/active(red)/active(blue) — рамка+точка+mono-подпись.
Слайдер: трек 5px + круглый thumb, подпись НАД треком (лейбл слева, значение справа mono).
ComboBox: закрытый + раскрытый popup (тёмный, зелёный selected). Скроллбар слим 8px.
Тултип. Карточки: ответ / HRD / защита / расширенный. Точки статусов. Контекст-меню.
Табы-сайдбар. Чекбокс. Эквалайзер-бары. Временная линейка mono. Toast-уведомление.

## 5. Темы
Обе темы обязательны: тёмная (базовая, #051424/#0F172A + мятный #4ADE80) и светлая
(#F5F5F7 + #0D7A36). Каждый атом — в обеих темах. Семантические цвета не темизируются:
ошибка #EF4444, срочное #FBBF24, STT-синий #60A5FA.

## 6. Задел на будущее (нарисовать макеты сразу, чтобы не возвращаться)
- **Onboarding / первый запуск**: 3 шага (выбор устройств звука → проверка STT/LLM
  с прогресс-статусами → готово). Сейчас просто вываливаются настройки.
- **Панель сценария мульти-агентов в оверлее**: быстрый селектор сценария
  (Собеседование/Брейншторм/Созвон с заказчиком/Карьера/1-на-1) с цветовой кодировкой агентов.
- **Экран экспорта/протокола**: предпросмотр AI-протокола встречи с action items,
  кнопки «копировать/сохранить .md».
- **Мини-режим оверлея**: строка 560×80 — только статус + последний ответ (для маленьких экранов).
- **Диалог обновления** и **краш-диалог** (после самозавершения watchdog: «приложение
  зависло и было перезапущено, отправить лог?»).
- **Индикатор здоровья сервисов** в тайтлбаре: STT (Docker) / LLM (локальный сервер) — зелёная/красная точка.

## 7. Технические ограничения для дизайнера
- WPF: без размытия фона за окном (glassmorphism имитируем полупрозрачными слоями).
- Шрифты только системные Windows: Segoe UI (тексты) + Cascadia Mono (данные/тайминги).
- Иконки отдавать как SVG path data (одна path на иконку — портируем в XAML Path).
- Цвета указывать hex + к какому токену темы относится (BgBrush/AccentBrush/...).
- Оверлей до 40% прозрачности — контраст текста проверять на пёстром фоне.
- Минимальная ширина оверлея 420px — все зоны должны выживать.
